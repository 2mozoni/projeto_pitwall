# 🏎️ PitWall | Grande Prêmio de São Paulo

Uma landing page responsiva dedicada ao GP de São Paulo de Fórmula 1. Este projeto foi desenvolvido inteiramente com **HTML5** e **CSS3** como parte das atividades da disciplina de Linguagem de Marcação (LIMA).

## 📖 Sobre o Projeto
O principal objetivo do PitWall é colocar em prática e consolidar os conceitos essenciais do desenvolvimento Front-end. A interface reúne informações detalhadas sobre o evento, o grid de pilotos, a tabela atualizada do campeonato e um formulário funcional para reserva de ingressos.

## 💻 Stack Tecnológico

*   **HTML5**: Código estruturado de forma semântica e acessível.
*   **CSS3**:
    *   Uso de variáveis (`:root`) para padronização e gerenciamento do tema.
    *   Criação de layouts modernos e flexíveis com **Flexbox** e **CSS Grid**.
    *   Efeitos visuais avançados, como gradientes com recortes (`clip-path` / `linear-gradient`) e a criação da clássica "zebra" de pista de corrida com `repeating-linear-gradient`.
    *   Design 100% responsivo utilizando `@media queries`, adaptando o conteúdo para dispositivos móveis.
*   **Google Fonts**: Tipografia *Titillium Web* para um visual esportivo e moderno.
